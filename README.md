# WorthIt AI

**A Machine Learning-Based Purchase Decision Support System**

## About the Project

WorthIt AI is a machine learning-based decision support system designed to help students and young adults make better decisions when they need an item.

Instead of automatically recommending a new purchase, it evaluates different factors and suggests a suitable action based on the user's needs, budget and available alternatives.

## Possible Recommendations

The system predicts one of seven possible actions:

- Reuse
- Repair
- Borrow
- Rent
- Buy Second-hand
- Buy New
- Postpone

## Features

- Takes 14 input features into consideration.
- Uses a Random Forest classification model for predictions.
- Includes a Decision Tree model for comparison.
- Provides recommendations through an interactive Streamlit application.

## Machine Learning

The project uses a synthetic dataset containing 2,800 records across seven target classes. A Decision Tree and a Random Forest classifier were trained and evaluated.

The Random Forest model achieved **98.57% test accuracy** on this synthetic dataset.

*Note: This result measures how well the model predicts labels generated by the project's synthetic labelling rules. It does not represent accuracy on real-world user decisions.*
