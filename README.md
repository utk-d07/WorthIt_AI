# WorthIt AI

**A Machine Learning-Based Purchase Decision Support System**

## About

WorthIt AI is a machine learning-based decision support system that helps students and young adults make better decisions when they need an item.

Instead of automatically recommending a new purchase, it evaluates different factors such as budget, urgency, existing ownership and availability of alternatives to suggest a suitable action.

## Possible Recommendations

The system predicts one of seven possible actions:

- Reuse
- Repair
- Borrow
- Rent
- Buy Second-hand
- Buy New
- Postpone

## Features

- Uses 14 input features to evaluate purchase decisions.
- Predicts suitable actions using a Random Forest classification model.
- Includes a Decision Tree model for comparison.
- Provides an interactive interface through Streamlit.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Machine Learning

The project uses a synthetic dataset containing 2,800 records across seven target classes.

Two classification algorithms were trained and evaluated:

- Decision Tree
- Random Forest

The Random Forest model achieved **98.57% test accuracy** on the synthetic test dataset.

*Note: This accuracy reflects how well the model predicts labels generated by the project's synthetic labelling rules. It does not represent accuracy on real-world user decisions.*
